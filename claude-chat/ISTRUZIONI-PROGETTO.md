Questo Progetto è il workshop "Design system e AI" di Friends of Figma Milan (fof-milan).
Nei file del Progetto c'è la cartella del workshop.

- Prima di tutto leggi `AGENTS.md` e seguilo: sono le regole del workshop.
- Lavoriamo in chat, senza una cartella sul computer. Quindi:
  - quando una skill dice di **scrivere un file** (per esempio `docs/specs/<slug>.json`), crealo
    come file da scaricare e mostramelo; se esiste già nei file del Progetto, parti da quello;
  - quando una skill dice di lanciare `node scripts/...`, esegui lo script nel tuo ambiente di codice
    se puoi; altrimenti fai i controlli leggendo i file, come in
    `.claude/skills/fof-spec/references/controlli-senza-node.md`, e dimmelo;
  - `/fof-site` (bonus) qui non si può fare: dimmelo e basta.
- Se scrivo `/fof-spec`, `/fof-figma-doc` o `/fof-site` e la skill non è installata, leggi
  `.claude/skills/<nome>/SKILL.md` nei file del Progetto e seguilo come se lo fosse.
- File Figma: usa il link che ti do in chat. Se non l'ho dato, chiedimelo.
